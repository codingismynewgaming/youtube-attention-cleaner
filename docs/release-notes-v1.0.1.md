# YouTube Attention Cleaner 1.0.1

## Deutsch

- Drei-Punkte-Menüs bleiben über abgeblendeten Nachbarvideos sichtbar und anklickbar.
- Gleichzeitige YouTube-Tabs überschreiben ihre Verlaufseinträge nicht mehr.
- Shorts werden nach zwei aktiven Sekunden zuverlässig erfasst.
- Wiederverwendete Videokacheln übernehmen keine Erfassungszeit eines anderen Videos.
- Absichtlich geöffnete Videos bleiben von der Ausblendung ausgenommen.
- Zurücksetzen verwirft veraltete Schreibanfragen. Bestehende Daten werden beim Update migriert.
- Der Verlauf wird in Speicherblöcke aufgeteilt. Abgelaufene Einträge werden bereinigt und Speicherfehler weitergegeben.
- Die Erfassung nutzt gezielte Beobachter statt dauernder Komplettscans und pausiert in ausgeblendeten Tabs.
- Popup-Zähler, schnelle Einstellungsänderungen und Reset-Fehlermeldungen sind korrigiert. Null Prozent entfernt auch den Graufilter.
- Chrome- und Edge-Quellen laden ihre Content-Module über einen passenden Loader.
- README und vorbereitete Store-Beschreibung stehen auf Deutsch und Englisch bereit.

## English

- Three-dot menus stay visible and clickable above dimmed neighbouring cards.
- Concurrent YouTube tabs no longer overwrite each other's history entries.
- Shorts are recorded after two active seconds.
- Reused video cards cannot inherit another video's tracking time.
- Intentionally opened videos remain excluded from dimming.
- Reset rejects stale write requests. Existing history is migrated during the update.
- History is split into storage chunks. Expired records are cleaned up and storage errors are surfaced.
- Targeted observers replace continuous full-page polling; tracking pauses in hidden tabs.
- Popup counts, rapid preference changes and reset error handling are corrected. Zero percent also removes the greyscale effect.
- Chrome and Edge sources use an appropriate content-module loader.
- README and prepared store descriptions are available in German and English.
