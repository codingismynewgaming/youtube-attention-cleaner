# Kostenloser Vermarktungsplan: Dim + Filter Seen YouTube Videos

Dieser Vermarktungsplan beschreibt, wie die Browser-Erweiterung **Dim + Filter Seen YouTube Videos** organisch, datenschutzfreundlich und kostenlos über verschiedene Plattformen und Kanäle bekannt gemacht wird.

## 1. Kanäle nach Priorität

1. **Reddit** (`r/firefox`, `r/youtube`, `r/SideProject`, `r/opensource`)
   - **Format:** Vorstellungspost mit einem kurzen Vorher/Nachher-GIF, das das Problem doppelter YouTube-Empfehlungen und die automatische Abblendung durch die Erweiterung zeigt.
   - **Fokus:** Echte Problemlösung für genervte Nutzer, Offenlegung als Open-Source-Projekt.

2. **Hacker News** (`Show HN`)
   - **Format:** `Show HN: Dim + Filter Seen YouTube Videos – Open-source extension to fade duplicate recommendations`
   - **Fokus:** Link direkt auf das GitHub-Repository, technischer Hintergrund zur Filterung und lokalen Speicherung ohne Telemetrie.

3. **AlternativeTo**
   - **Format:** Eintrag als kostenlose, quelloffene und datenschutzfreundliche Alternative zu bestehenden Tools wie *Unhook* und *FreshView*.
   - **Fokus:** Klare Hervorhebung der lokalen Ausführung und des Verzichts auf externe Tracking-Dienste.

4. **Lemmy** (`!firefox@lemmy.ml`) & **Mozilla Discourse**
   - **Format:** Community-Beitrag mit Fokus auf lokalen Datenschutz (keine externen Server, keine Telemetrie, Open Source).
   - **Fokus:** Ansprache der Community, die besonderen Wert auf Privatsphäre und Firefox-Kompatibilität legt.

5. **GitHub Topics & Awesome-Listen**
   - **Maßnahmen:**
     - Repository-Topics setzen: `firefox-addon`, `chrome-extension`, `edge-extension`, `youtube`, `webextension`.
     - Pull Requests bei passenden Awesome-Listen (z. B. Awesome Browser Extensions, Awesome Open Source) einreichen.

6. **Dev.to & Medium**
   - **Format:** Technischer Artikel über die Entwicklung der Erweiterung und den Ansatz gegen sich wiederholende Empfehlungen auf YouTube.
   - **Fokus:** Architektur, WebExtensions API und Herausforderungen beim Erkennen dynamischer YouTube-DOM-Änderungen.

---

## 2. Vorbereitung vor dem Start

- Ein prägnantes 5-Sekunden-GIF der abgeblendeten Videokacheln direkt im Browser aufnehmen und für Posts bereithalten.
- Direkte Links zu allen Stores (Firefox Add-ons, Chrome Web Store, Edge Add-ons) sowie zum GitHub-Repository einsatzbereit halten.
